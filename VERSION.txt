# HKJC 足球價值投注系統 v1.1.4
2026-10-11 v1.1.4 修 Railway 建置失敗：nixpacks.toml 原本自訂咗 setup/install phases
（nixPkgs = ["python311"]），會蓋過 Nixpacks 內建 Python provider，令 image 只有 python 而冇 pip
→ RUN pip install --upgrade pip 出 "pip: command not found"、exit code 127。現改成極簡
nixpacks.toml（只留 [variables] NIXPACKS_PYTHON_VERSION=3.11 同 [start]）；railway.json 亦移除
buildCommand（避免喺 Nixpacks 環境外跑 pip），只保留 builder=NIXPACKS 同啟動／健康檢查設定。

2026-10-11 v1.1.3：修正掃描／賠率更新只用「日曆日」做界，令跨午夜（凌晨開賽）嘅場漏咗 ——
午夜前後會出現 checked 0、`selftest.py` 亦會失敗。改用「以現在為中心嘅滾動時間窗」
（掃描：-90 至 +max_minutes 分鐘；賠率更新：+6 小時）。實測 23:34 由 checked 0 變為正常掃到場。

2026-10-11 v1.1.2：通知失敗時會顯示 Telegram 真正原因（例如 telegram 401: Unauthorized），
唔再只出 "not sent: None"，方便判斷 token 打錯／已被 revoke。

2026-10-11 v1.1.1 修 Windows bug：.env 一開就會讀到 Railway 專用嘅 DB_PATH=/data/football.db，
令本機出 FileNotFoundError: [WinError 2] ...: '/data'。/data 已改成註釋（本機留空＝用
repo 內 data\football.db）；config.py 見到 Windows + POSIX 絕對路徑會自動退回本機路徑並印原因；
db.py 寫唔入目標夾會退回本機 data 夾（唔會整個程式死）；requirements 加 tzdata（Windows 需要）。

2026-10-11 v1.1.0：config.py 自己讀 .env（backend/ 或 repo 根目錄都可以，唔需要 python-dotenv）；
新增 `cli.py env` 診斷指令（Python／程式版本、.env 讀到邊個檔、資料庫、token、門檻）；
notify 未設定時會提示去邊度填；README／手冊加 Windows（py）同資料夾位置說明。
